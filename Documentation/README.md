# EchoPaws Documentation Hub

This directory consolidates the existing Markdown sources in the repository into a set of agent-ready reference documents. Use these documents as the authoritative context for future development work on the EchoPaws project.

## Document Index

- **Project Overview**: `Project-Overview.md`
- **Character Canon & Visual Specs**: `Character-Canon.md`
- **World Bible & Setting Canon**: `World-Bible.md`
- **Image Asset Register**: `Image-Assets.md`
- **Source Map (original files)**: `Source-Map.md`

## How to Use

1. Start with **Project-Overview** for the high-level product and persona framing.
2. Use **Character-Canon** for appearance, behavior, and prompt-ready descriptions.
3. Reference **World-Bible** for setting, geography, symbols, and narrative anchors.
4. Consult **Image-Assets** to locate canonical visual references.
5. Use **Source-Map** to trace any item back to its original Markdown source.

## Notes

- No `SPEC.md` file exists in the repository at this time. The documents above consolidate all available Markdown sources.
- If new specs are added later, update both the Source Map and the relevant consolidated document.
